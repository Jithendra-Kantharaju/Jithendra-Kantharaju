## 🚀 Featured Projects

### 🤖 [Enterprise CloudOps AI Platform](https://github.com/Jithendra-Kantharaju/enterprise-cloudops-ai-platform)
> **Problem:** Incident triage took 60+ minutes with no unified view of EKS health, CloudWatch, and Prometheus.

Built a production AIOps platform deploying 8 microservices to live EKS 1.34 via Terraform and ArgoCD.
Includes **"Kira"** — an AWS Bedrock Agent (Nova Lite) with Lambda tools that auto-diagnoses incidents
in real time. Also ships a RAG assistant (FastAPI + ChromaDB + OpenAI) with prompt guardrails.

**Stack:** `EKS 1.34` `Terraform` `GitHub Actions` `ArgoCD` `AWS Bedrock` `FastAPI` `ChromaDB` `Prometheus`

**Result:** MTTR dropped from **60+ minutes → under 5 minutes**

---

### 🔒 [DevSecOps Reference Infrastructure](https://github.com/Jithendra-Kantharaju/devsecops-reference-infrastructure)
> **Problem:** Static credentials and unscanned images were reaching production undetected.

Zero-trust Kubernetes security pipeline with Trivy image scanning, OPA/Conftest policy gates,
Vault secrets injection, IAM OIDC (no static credentials), Falco runtime detection,
and CloudTrail audit logging to encrypted S3.

**Stack:** `GitHub Actions` `ArgoCD` `HashiCorp Vault` `Falco` `OPA/Conftest` `Trivy` `Datadog` `OpenTelemetry`

**Result:** Security audit time dropped **60%** — zero critical CVEs in production
