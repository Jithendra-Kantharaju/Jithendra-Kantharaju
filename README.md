## 🔥 Featured Projects

### 🤖 [Enterprise CloudOps AI Platform](https://github.com/Jithendra-Kantharaju/enterprise-cloudops-ai-platform.git)
An intelligent, production-grade cloud ecosystem orchestrating 7 containerized microservices over multi-AZ AWS infrastructure.
* **Infrastructure as Code:** Packaged completely inside modular Terraform templates to spin up custom VPCs, EKS clusters, ECR, and IAM configurations—driving environment blueprint configuration delivery time down by 80% (from 45 to 12 minutes).
* **AIOps Remediation:** Built an automated SRE troubleshooting assistant powered by an **AWS Bedrock Agent** coupled with 3 custom Lambda action groups. The agent consumes metrics and event streams across CloudWatch, Prometheus, and EKS cluster states, shrinking MTTR by 91% (from 60 minutes down to 5 minutes).
* **GitOps & Cost Optimization:** Synced application deployments using ArgoCD to perform strict continuous drift detection and state-reconciliation. Integrated a granular Prometheus and Grafana metrics pipeline that pinpointed idle workloads, surfacing 25-30% in cloud infrastructure cost savings.

`AWS Bedrock` `Amazon EKS` `Terraform` `AWS Lambda` `ArgoCD` `Prometheus` `Grafana` `FinOps`

### 🔐 [DevSecOps Reference Infrastructure](https://github.com/Jithendra-Kantharaju/devsecops-reference-infrastructure.git)
A deep zero-trust engineering baseline designed to safeguard containerized Kubernetes application lifecycles from building to running in runtime.
* **Shift-Left Security:** Configured secure secret fetching via HashiCorp Vault, localized cluster segregation using native Kubernetes Network Policies, and introduced automated OPA/Conftest policy-as-code evaluations to fully remove hardcoded secrets and save 60% of compliance manual audit overhead.
* **Continuous Monitoring & Shielding:** Configured runtime kernel profiling using Falco combined with AWS CloudTrail hooks to route real-time threat-alerts in less than 5 seconds. Connected tracing and logs via OpenTelemetry into a unified Datadog APM dashboard to achieve FinOps target reductions and cut MTTR by 40%.

`GitHub Actions` `HashiCorp Vault` `Falco` `OPA/Conftest` `Trivy` `OpenTelemetry` `Datadog` `Kubernetes`

### 🚀 [GitOps CI/CD Pipeline on AWS EKS](https://github.com/Jithendra-Kantharaju/AWS-GitOps-Automation-Actions)
A dual-repository GitOps implementation segregating cloud infrastructure templates from the application lifecycle logic. Uses declarative GitHub Actions automation engines to trigger build artifacts and push image layers to Amazon ECR, running code health scanning via Maven and SonarCloud before release.

`Terraform` `GitHub Actions` `Docker` `Amazon ECR` `Helm` `SonarCloud` `EKS`
