## Featured projects

### LedgerGuard

**AI-assisted invoice processing with policy checks and human review**

Extracts invoice data, checks for duplicates, and matches invoices against purchase orders and receipts. The workflow routes exceptions to reviewers and records shadow approvals without posting transactions.

- **Evaluation:** Zero incorrect auto-approvals across 144 development cases in shadow mode.
- **Stack:** Python, FastAPI, LangGraph, OpenAI API, PostgreSQL, pgvector

[View LedgerGuard on GitHub](https://github.com/Jithendra-Kantharaju/ledgerguard)

### Enterprise CloudOps AI Platform

**AWS EKS platform with GitOps delivery and AI-assisted incident triage**

Deployed eight services to AWS EKS, including a retrieval-augmented generation (RAG) assistant. A LangGraph agent uses CloudWatch, Prometheus, and Kubernetes signals to classify incidents.

- **Delivery:** Reduced deployment time from 45 to 12 minutes with parallel GitHub Actions builds and Argo CD.
- **AI evaluation:** Classified 15 of 16 simulated incidents correctly (93.8%). The RAG assistant handled 21 of 22 refusal test cases correctly (95.5%).
- **Stack:** AWS EKS, ECR, Terraform, GitHub Actions, Helm, Argo CD, LangGraph, FastAPI, ChromaDB

[View Enterprise CloudOps AI Platform on GitHub](https://github.com/Jithendra-Kantharaju/enterprise-cloudops-ai-platform)
